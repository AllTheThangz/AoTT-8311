Running management settings

Virtual SFP EEPROM configuration still does not prove what the router sees. No settings are changed.

PON and OMCI configuration readback

Compare four noncredential PON/OMCI overrides with configured vendor values and the separate live PON registration state. A UCI match or O5.1 association does not prove the OLT applied an individual setting or that Internet service works. This is read-only.

Identity and credential override status

Check nine stored overrides without displaying identifiers, credentials, password hashes, lengths or fingerprints. Unset is not a failed read: a vendor default or legacy value may still apply. This does not test ISP authentication, root login, live OMCI use or reboot persistence.

Reported OMCI identity and software metadata

Check ten saved reporting fields without disclosing identity strings, stored software-version labels or matching patterns. A valid stored value does not prove that the OLT received it. Reported active/committed bank overrides do not change or confirm the actual boot bank. No settings are changed.

ISP VLAN configuration and reconciliation

Compare the three saved VLAN settings with any last successful built-in reconciliation record. The running VLAN daemon and a recorded topology hash do not prove live traffic-control rules, ISP throughput or Internet access. Nothing is changed.

Advanced system and host readback

Read saved boot, SFP pin and Ethernet override settings. Pin voltages, process presence and negotiated host speed are observations, not proof that an advanced setting was applied. Root credentials and hashes are excluded. No settings are changed.
