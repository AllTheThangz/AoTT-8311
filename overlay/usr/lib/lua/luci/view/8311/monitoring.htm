Monitoring & telemetry

Use your own syslog receiver or Prometheus-compatible collector. AoTT-8311 exposes bounded monitoring data, but does not store historic metrics or bundle a monitoring server.

Scope and security

All settings apply to this ONU only. Collector scheduling, storage, dashboards and notification rules are managed externally. Browser metrics use administrator authentication. External collectors require HTTPS, an exact allowed client IP and a separate read-only credential. Remote log reception must be confirmed on the receiving server.
