Import operator-owned certificate

Import an existing server certificate and matching unencrypted private key. PEM or DER leaf/key material is accepted. An optional PEM chain may contain up to three CA certificates. Import validates the requested SANs, current validity, CA/leaf structure, chain ordering, and the exact pair with a native uhttpd TLS handshake bound only to loopback. It does not change the active HTTPS certificate.
